## Описание  																
Этот проект направлен на анализ коммерческой эффективности бразильского маркетплейса Olist. Главным результатом выполнения проекта является интерактивный дашборд в Power BI для мониторинга KPI. В ходе работы были также определены ключевые факторы, влияющие на удовлетворенность клиентов. Как итог, были предложены рекомендации для улучшения деятельности маркетплейса и повышения клиентоориентированности.

## Данные
* Источник: [**Brazilian E-Commerce Public Dataset by Olist**](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)  
* Объем: 9 таблиц, 100 000 строк. Объяснения типов данных, первичных ключей находятся в [**файле**](docs/data_dictionary.md)
