# Анализ эффективности продаж и логистики маркетплейса Olist

![Dashboard Preview](assets/dashboard_screenshot.png)

## Описание																
Этот проект направлен на анализ эффективности продаж и логистики бразильского маркетплейса, а также создание единой системы аналитики для мониторинга KPI. В ходе работы были также определены ключевые факторы, влияющие на удовлетворенность клиентов, и предложены рекомендации.

## Данные
— Источник: [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)  
— Объем: 9 таблиц, 100 000 строк. [Data Dictionary](docs/data_dictionary.md)
